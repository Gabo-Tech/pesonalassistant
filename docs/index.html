Why it is free

What it does

  • Notes Title, markdown, and a live preview. Search stays on the device.
  • Agenda An in-app calendar with all-day events, repeats, and an alert before they start. Reminders and tasks sit beside it.
  • People A preferred way to reach each person: WhatsApp, Signal, or a call.
  • Alarms In-app alarms. Daily if you say every day. Dismiss or snooze.
  • Confirm WhatsApp, Signal, and X open a draft. You tap Send, or say send.
  • Two languages English or Spanish for the interface, speech, and spoken replies.
  • Your model Start light at 0.5B on the phone. A cloud key in Settings is optional.
  • Live facts Prices, news, and public events. One search. Only that query leaves the phone.

Questions

  • Where does it run? Speech and the language model run on the phone. Notes, the calendar, tasks, reminders, and people stay in a local database.
  • What leaves the phone? A live-fact search sends only that query. An open question leaves only if you add a cloud key. Schedule questions stay on the phone.
  • Does it send messages? No. WhatsApp, Signal, and X open a draft, and only after you confirm.
  • How do I install it? Download the APK and allow install from this source. It is for Android 8 and up. There is no store listing and no account.

How to start

  1. Install the APK Android will ask you to allow this source. That is expected for a sideload.
  2. A short first open Privacy, microphone, wake word, then optional models. You can skip the download and type.
  3. Talk or type Tap the orb, say the wake word, or use the composer. Confirm before anything leaves.
