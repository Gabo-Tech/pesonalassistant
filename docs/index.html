Confirm

Nothing sends itself

WhatsApp, Signal, and X open a draft. You tap Send, or say send.

Wake

A word you choose

Default is “computer”, or “computadora” in Spanish. Always-listen is optional. Typed commands still work.

Start

Three steps. Then it is yours.

01

Install the APK

Android will ask you to allow this source. That is expected for a sideload.

02

A short first open

Privacy, microphone, wake word, then optional models. You can skip the download and type until you are ready.

03

Talk or type

Tap the orb, say the wake word, or use the composer. Confirm before anything leaves the phone.

Privacy

Speech recognition and the language model run on this device. Notes, reminders, alarms, and remembered facts live in a local database. WhatsApp, Signal, and X only open a draft after you confirm — tap Send or say send.
